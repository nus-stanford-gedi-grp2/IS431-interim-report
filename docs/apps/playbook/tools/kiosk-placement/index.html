AI review settings

The built-in engine always scores placements. With an OpenAI key you also get a written expert review based on its measurements.

The key is sent only to api.openai.com, directly from this page. Avoid shared or production keys on shared computers.

Scoring formulas

Observed measurements (metres, m², degrees, counts, yes/no, each with how to measure it on site) → factors → criteria (0–100) → overall. Each score gets one of four grades (A–D; thresholds editable below) and is shown grade first, then bucket and score. Any D criterion caps the overall at D. Edit any formula; changes preview live on the selected kiosk.

Click a name to insert it into the formula you're editing.
